# Skyline Bank of India – FD Certificates & Maturity Miles

A DApp for a fictional bank, built for the NCI Blockchain Technologies project. It runs on the Ethereum Sepolia testnet.

- **SBOIFDCertificate (ERC-721):** soulbound fixed-deposit certificates. Contract `0x345AdD466e9faDee05a217209cDD16ebFAAb25C9`
- **SBOIRewardToken (ERC-20, SBOIR):** Skyline Maturity Miles, 1 mile = Rs 1 in bank perks. Contract `0xEc98D40Bfebe393F114fEa511779Ad6B3F8333aA`

Open the site, connect MetaMask on Sepolia, and use My Banking, Verify FD and the Bank console.
The Bank console unlocks only for the bank's issuer wallet.
